# 🔬 Can we raise the NY-ORB's profitability? — honest verdict

Tested three enhancement paths walk-forward (tune IS 2015–21 / judge OOS 2022–26, real costs, 2% risk). Base reference: **NY-ORB rb4 = OOS +344%, PF 2.05, maxDD −23%.**

## 1. Scaling / pyramiding — ❌ HURTS
Add units as the trend extends + ATR trail (your "scale more positions"). IS-selected best, on OOS: **−20%, PF 0.85, maxDD −52%, WR 22%.** It turned the winner into a loser. The edge lives in the disciplined fixed-4R exit; pyramiding buys higher and the trail hands profit back on pullbacks. **Do not scale.**

## 2. 40-scalps/day on M5 — ❌ RUIN
The "~40 setups/day" idea, tested on real M5 gold (all sessions, tight 1–2R targets): **−97% to −98%, PF 0.22–0.39, account → ~$4** at every setting — even at 46% win rate. 600 trades × real spread = death. This is the cost wall, proven: at ~$0.40 round-trip against a $1–3 scalp target, costs eat 15–40% of every trade and compound you to zero. **High-frequency scalping gold does not work net of costs.** (London-on-M15 also ruined: −94%.)

## 3. More breakout triggers (tighter range, rb2) — ⚠️ RAISES RETURN, RAISES RISK (a trade-off, not a free lunch)
| | OOS return | OOS PF | OOS maxDD | **IS maxDD** | trades |
|---|---|---|---|---|---|
| **rb4 (base)** | +344% | **2.05** | −23% | **−22%** | 126 |
| **rb2 (more triggers)** | **+426%** | 1.69 | −27% | **−47%** | 198 |

rb2 fires ~57% more trades and made more OOS — but its **PF is lower (1.69 vs 2.05)** and its **in-sample drawdown was −47%** (the honest expectation), nearly double rb4's. A chunk of rb2's OOS shine is the 2025 gold melt-up (+136% that year). It survives 2×/3× cost stress and is profitable every OOS year, so it's *real* — just **more aggressive**, not strictly better. Use rb2 only if you can stomach ~−45% drawdowns for more nominal return.

## Bottom line
- **The base NY-ORB (rb4) is already near the efficient frontier for this edge.** Best risk-adjusted (PF 2.05, −23% DD).
- You **cannot raise the win rate** (33%) without lowering the RR target, which the full grid showed *reduces* expectancy. 33% WR is structural to a high-RR trend-breakout system — the money is in the few big winners.
- **Neither "more size" nor "more trades" helps** — both destroy the edge via cost drag / giving back profit. The edge is *selectivity*.
- The only honest "more profit" lever is **more risk** (rb2, or higher risk%) — which is more drawdown, not more edge.
- AMD/FVG on LTF: the LTF-frequency direction was tested (M15/M5) and added cost-drag/ruin; the orthodox AMD engine already tested **break-even** over 11yr in prior audits. A dedicated AMD-long backtest can be run on request, but the evidence says added LTF structure reduces, not raises, profitability here.

**Recommendation:** keep rb4 as the core. If you want more return and accept the risk, run rb2 — but size *down* (1–2%) because its real drawdown is ~−45%. Don't scale, don't scalp.
